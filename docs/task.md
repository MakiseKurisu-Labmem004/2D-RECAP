# 当前任务：3R侧抓、旋转与稳定放置

任务标识`pedestal_upright`，机器人`arm3r`，版本`arm3r_upright_smooth_v1`。这是当前唯一支持的任务。基础参数位于configs/base.yaml，CPU/GPU入口分别为arm3r.yaml和arm3r_cuda.yaml。

肩、肘、腕三个y轴旋转关节通过有限力矩PD驱动，连杆长度30、28 cm，工具偏置7 cm。物体12×4×4 cm、80 g，保留x/z平移和绕y旋转。两指耦合，最大开度8 cm。没有mocap运动、物体吸附、焊接或成功后冻结。

动作4维，归一化到[-1,1]：实际TCP位置加每轴最多1 cm、实际末端角度加最多3°，最后一维映射绝对开度0–8 cm。固定分支IK、增量回退和关节目标变化限制后执行物理步进。20 Hz控制，每步20个0.0025 s物理子步。

夹爪总开度参考速度限制0.06 m/s、加速度0.4 m/s²、响应时间0.2 s，单指伺服kv=8。限制施加在伺服参考，不直接修改qpos/qvel；接触和外力仍由物理仿真决定。平滑器的目标、参考和速度保存在快照中。专家等待真实闭合稳定后试抬，释放等待真实开爪。

观测40维：夹爪9、物体7、目标4、台座5、相对量6、几何3、关节角/速度6。不输入步号、剩余预算或专家阶段。策略与价值网络各自6×128 ReLU，价值输出201个分布bins。

成功要求物体在目标区、中心横向误差<1.2 cm、竖直误差<5°、桌面支撑、线速度<1.5 cm/s、角速度<0.15 rad/s、夹爪开度>4.8 cm、TCP离物体>10 cm且双指/掌部无接触，并连续保持20步。全部机械臂部件的无支撑检查是设计文档中的待补齐项。平面约束排除了面外倾倒。

专家无任务期限，阶段停滞保护产生aborted而不是普通失败。策略rollout与评估暂定300步。普通奖励-1、成功终止0、任务失败或超时-C_fail，gamma=1；采专家后统一冻结C_fail和价值支持区间。空抓及可恢复掉落不立即终止。

当前ID分布：台座高12–15 cm、悬伸3.8–4.6 cm、目标x=12–20 cm。当前外推：短悬伸3–3.5 cm、高台座17–19 cm。尚未实现设计文档中的组合OOD采样与初始姿态扰动。

实现职责：env.py提供公共仿真状态与接触接口；upright.py提供任务几何、成功条件与闭环专家；arm3r.py提供关节链与IK控制；gripper.py提供开度平滑；tasks.py只构造3R环境。训练和评估通过配置复用公共入口。

当前实例237步（11.85 s）成功，视频位于runs/arm3r_smooth_gripper_demo/rollout.mp4。ID、短悬伸、高台座各12条专家均成功，长度234–247步，证据位于runs/arm3r_gripper_smoothing_check/physics.json。它们是物理抽检结果，不是学习策略性能。更完整研究协议见[详细设计](arm3r_design.md)。
