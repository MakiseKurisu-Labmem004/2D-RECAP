# 当前任务：3R侧抓、旋转与稳定放置

任务标识`pedestal_upright`，机器人`arm3r`，数据版本`arm3r_upright_stable_target_no_relative_v2`。这是当前唯一支持的任务。基础参数位于configs/base.yaml，默认model.device为cuda，所有实验面向GPU服务器；arm3r.yaml为默认入口，arm3r_cuda.yaml为显式CUDA入口。MuJoCo物理步进仍使用CPU。

肩、肘、腕三个y轴旋转关节通过有限力矩PD驱动，连杆长度30、28 cm，工具偏置7 cm。物体12×4×4 cm、80 g，保留x/z平移和绕y旋转。两指耦合，最大开度8 cm。没有mocap运动、物体吸附、焊接或成功后冻结。

动作4维，归一化到[-1,1]：实际TCP位置加每轴最多1 cm、实际末端角度加最多3°，最后一维映射绝对开度0–8 cm。固定分支IK、增量回退和关节目标变化限制后执行物理步进。20 Hz控制，每步20个0.0025 s物理子步。

夹爪总开度参考速度限制0.06 m/s、加速度0.4 m/s²、响应时间0.2 s，单指伺服kv=8。限制施加在伺服参考，不直接修改qpos/qvel；接触和外力仍由物理仿真决定。平滑器的目标、参考和速度保存在快照中。专家等待真实闭合稳定后试抬，专家释放阶段等待真实开爪；任务可能在释放撤离完成前就达到成功条件。

观测34维：夹爪9、物体7、目标4、台座5、几何3、关节角/速度6。不输入显式相对位置和相对姿态误差。不输入步号、剩余预算或专家阶段。策略与价值网络各自6×128 ReLU；普通BC/Value输入34维，条件策略输入35维（含1维优势条件），价值输出201个分布bins。

`environment.success_rule: stable_target`只检查目标区的稳定竖直状态：物体中心x距目标中心不超过4 cm、接触桌面、竖直误差<5°、线速度<1.5 cm/s、角速度<0.15 rad/s，连续保持20步（1秒）。任一条件不满足则保持计数清零。不要求物体整个投影都在目标区，也不检查更紧的中心误差、底部高度、夹爪开度、撤离距离或机器人无接触。夹爪仍接触或夹持时也允许成功。平面约束排除了面外倾倒。

专家无任务期限，阶段停滞保护产生aborted而不是普通失败。策略rollout与评估暂定300步。普通奖励-1、成功终止0、任务失败或超时-C_fail，gamma=1；采专家后统一冻结C_fail和价值支持区间。空抓及可恢复掉落不立即终止。

当前统一ID分布：台座高12–19 cm、悬伸3.0–4.6 cm、目标x=12–20 cm，三个参数独立均匀采样；原短悬伸、高台座范围、区间间隙及交叉组合都进入训练。专家、策略rollout、验证和正式测试使用相同范围、不同种子，evaluation.suites仅为[id]，无额外场景覆盖。恢复状态池仍单列诊断，不作为OOD。初始姿态扰动尚未实现。

实现职责：env.py提供公共仿真状态与接触接口；upright.py提供任务几何、成功条件与闭环专家；arm3r.py提供关节链与IK控制；gripper.py提供开度平滑；tasks.py只构造3R环境。训练和评估通过配置复用公共入口。

当前成功定义的验证记录见[验证记录](validation.md)，物理检查产物位于runs/arm3r_all_id_check/。更完整研究协议见[详细设计](arm3r_design.md)。

`expert_rollout.retreat_clearance`仅控制专家的撤离高度，不是成功门槛。原来的success_position_tolerance、release_clearance和table_height_tolerance已从基础配置移除。成功终止时刻改变，因此数据与奖励版本同时更新，旧数据不自动重新标注。
