# 3R 机械臂侧抓、旋转与稳定放置：研究方案

日期：2026-11-17。本文是当前原型之上的详细设计，不代表所有条目已经实现。标为“当前”的内容对应现有代码；“正式协议”与“待补齐”的内容是下一阶段工作。涉及任务分布、成功条件、奖励或观测的改动，应显式更新数据或奖励版本并新建run，不能接着使用旧分布的结果目录。

当前数据版本为 `arm3r_upright_stable_target_no_relative_v2`，默认观测已去掉相对关系，奖励版本为 `arm3r_upright_stable_target_v1`：每个物理子步限制总开度参考速度0.06 m/s、加速度0.4 m/s²，响应时间0.2 s，单指kv=8。专家按实际闭合反馈试抬，完整保存平滑器状态。当前成功定义已简化为目标区内稳定竖直，不要求释放或撤离；以下待补齐功能尚未全部实现，当前配置与运行说明见[任务说明](task.md)。

## 1. 研究问题与任务边界

使用有肩、肘、腕三个旋转关节的平面机械臂，从台座边缘侧向夹住水平长方体，经过试抬、抬升、约 90° 旋转、运输和下降，将它竖直放到桌面目标区，最终在桌面目标区保持稳定竖直。专家包含释放和撤离动作，但成功判定不等待它们完成。

研究问题分成四项：

1. 数值观测下，分布价值网络能否预测指定行为策略的实际后续回报？
2. n 步优势能否区分有效纠正、无效动作和进一步恶化的动作片段？
3. 相同数据和训练预算下，优势条件更新是否优于聚合 BC 与仅成功数据 BC？
4. 收益是否体现在统一场景分布中的空抓/滑移恢复，以及不同高度和悬伸量的组合中？

这些都是待实验回答的问题，不预设 RECAP 胜出，也不预设所有抓偏状态的价值都低。先固定数据比较，再进行在线迭代。

保留 x–z 平面：三个机械臂关节绕 y 轴转动，物体保留 x、z 平移及绕 y 旋转。夹爪两指耦合为一个开度。总控制接口仍为四维。当前是自定义教学机械臂，未对应厂商标定参数；平面约束排除了侧向滑落及面外倾倒，结论限于这一任务。

## 3. 动作接口与底层控制

策略和专家都输出 `a=[a_x,a_z,a_theta,a_open] ∈ [-1,1]^4`。末端表示夹爪 TCP。

```text
x_target     = x_actual + 0.01 * a_x        [m]
z_target     = z_actual + 0.01 * a_z        [m]
theta_target = theta_actual + (pi/60)*a_theta [rad]
opening      = 0.04 * (a_open + 1)          [m]
```

当前位置是仿真测得的位置，不是上一次命令目标。当前每个平移轴最大 1 cm，所以对角动作的位移范数最大为 √2 cm；这一约定必须在文档和所有方法间保持一致。

处理顺序固定为：网络输出 → 配置声明的探索噪声 → 归一化裁剪 → 单位转换与末端边界裁剪 → 固定分支 IK → 必要时缩短末端增量 → 关节增量限制 → 有限力矩 PD → 物理步进。全局可行性由场景验收保证，IK 回退只处理局部命令越界，不能充当避障规划器。

当前补偿使用 MuJoCo 的关节偏置力，经同一有限力矩执行器施加；它包含重力及速度相关项。不能把补偿作为绕过执行器力矩上限的额外外力。

数据中的 `action` 定义为真正提交给环境的、加噪并裁剪后的四维命令；它不是实测末端位移。正式协议另存原始网络输出、噪声、物理末端目标、IK 缩放、最终关节目标和执行器力矩。这样能区分策略失误、IK 投影与伺服跟踪误差。当前快照已含控制状态，但逐步动作审计字段仍需补齐。

## 4. 观测、网络与可观测性

当前数值观测为 34 维，不拼接相对位置和相对姿态误差：

| 分组 | 维度 | 内容 |
|---|---:|---|
| 夹爪 | 9 | TCP 位置/速度、姿态 sin/cos、角速度、开度/开度速度 |
| 物体 | 7 | 位置/线速度、姿态 sin/cos、角速度 |
| 目标 | 4 | 位置、目标姿态 sin/cos |
| 台座 | 5 | 边缘、宽度、高度、初始悬伸量、深度 |
| 物体几何 | 3 | 长、宽、厚 |
| 机械臂 | 6 | 三个关节角及角速度 |

关节角有受限连续区间，当前使用原始角度；物体及末端姿态用 sin/cos。物体两端等价，竖直成功误差按模 π 计算。观测不包含剩余步数、步号、专家阶段、成功标签或未来结果。接触与阶段用于专家反馈、环境管理和日志，当前策略没有接触特征输入。

策略与价值网络独立，均为六个 128 单元 ReLU 隐藏层，输出层不计入六层。普通策略为 34→6×128→4，再 tanh；条件策略额外输入一个二元条件，为 35→6×128→4；价值为 34→6×128→201 logits，经 softmax 后取支持点期望。两者不共享 backbone。

归一化只能使用各自训练分区，写入 checkpoint。策略从初始 BC warm start 时应保留兼容的归一化统计；若更换统计，必须显式处理输入函数的变化，不能只替换均值方差而声称初始函数相同。

由于任务期限和成功保持计数不进入网络，相同数值观测可能对应不同的剩余机会。V 是数据采样分布下的条件期望，不是完整有限时域的 Markov 价值，也不是几何对齐评分。所有诊断明确续跑策略和剩余预算；可增加“同一物理状态、不同剩余预算”的审计图展示这个限制，仍不把时间加入主实验输入。

## 5. 成功、失败、期限与奖励

当前成功条件按用户要求简化为目标区内稳定竖直：

- 物体中心横向位置位于目标中心±4 cm内，不要求整个水平包络落在区域内。
- 与桌面接触，竖直误差<5°。
- 线速度<1.5 cm/s，角速度<0.15 rad/s。
- 以上同时持续20个控制步，即1秒；中途不满足则计数归零。

不检查1.2 cm中心误差、4 mm底部高度、夹爪开度、撤离距离或机器人无接触。允许在夹爪仍接触/夹持时成功，因此成功率衡量稳定目标姿态，不代表已经独立释放。专家仍尝试释放与撤离，但环境可能更早终止。释放后独立站立可以作为额外诊断，不作为当前主任务门槛。

空抓、偏心抓、局部滑移和仍在工作区内的掉落不立即终止。物体越界等明确不可恢复事件是任务失败。数值异常、程序错误、用户取消和作业中断记为 aborted，不能伪装成任务失败。存在碰撞不自动判失败，避免把可恢复接触错误抹掉。

专家任务预算始终为 null，成功轨迹超过 200 或 300 步也保留。单阶段停滞保护是显式程序异常；当前为 400 步。物理验证的 1200 步保护同样不是专家任务期限。学习策略和正式评估暂用 H=300，即 15 s；根据完整专家长度、ID 验证及重试所需时间一次确定，随后全组固定。成功定义改变后，需用新版专家长度重新确认纠错时间，不能沿用更严格定义下的完成时间。

奖励保持：普通步 -1，成功终止步 0，真实失败或任务期限终止步 -C_fail，γ=1；终止奖励覆盖普通步，成功与期限同一步时成功优先。任务期限是任务定义内的终止，bootstrap=0；外部截断须续采或使用明确的 bootstrap 目标。当前 MC 路径只接受完整任务轨迹。

设专家最长成功轨迹为 L_max，H_max 为所有正式策略 rollout/评估预算的最大值，先采专家，再冻结：

```text
M = max(L_max, H_max)
C_fail = M                     # 也可配置，但必须 > M-1
success return at length T = -(T-1)
failure return at length T = -(T-1)-C_fail
value support = [-(H_max-1+C_fail), 0]
```

因此最快失败的 -C_fail 严格低于保证范围内最慢成功的 -(M-1)。例如所有专家长度不超过 300 且 H=300，C_fail=300，支持区间 [-599,0]；这是条件示例，当前 36 条物理检查不能替代正式专家采集后的冻结。

正式比较的各方法共用同一 contract。多个训练种子若共享专家数据也共享 contract；如果分别采专家，必须先汇总全组的 L_max 后再冻结。增加期限或纳入更长专家后应创建新版本并统一重算，不混用奖励定义。

201 个支持点使用相邻 bins 线性插值的软标签。标签越界立即报错；上述例子的 bin 间距约 2.995 个奖励单位，需观察价值误差对接近零的优势分类是否造成影响，不能依靠硬裁剪掩盖问题。

## 6. 专家、BC 与行为数据

专家状态机采用反馈切换：张开 → 侧面预对齐 → 接近悬伸端 → 闭合 → 试抬并验证 → 安全抬升 → 旋转 → 运输 → 下降接触桌面 → 释放 → 撤离 → 等待稳定。试抬同时检查双指接触与物体实际离开支撑；旋转和下降根据真实物体姿态及夹爪相对物体的偏移调整目标。空抓回到预对齐；滑移后根据物体状态选择重新对齐或重抓。

安全高度需要考虑整段旋转中物体、手指、掌部和机械臂的扫掠包络；当前专家使用保守高度规则，下一阶段补充净空检查和边界场景验收。状态机仅用于采专家和构造受控诊断，不在策略 rollout 中提供兜底。

专家以成功示范条数为采集目标，保留所有尝试日志。初始 BC 只用成功示范；未成功的完整尝试及 aborted 不能悄悄删除以制造专家成功率。专家回报不进入默认价值训练，其无期限目标与策略的有期限目标不同。

初始 BC 用独立 ID 验证场景选 checkpoint，之后冻结网络与归一化。新的训练种子采集固定回合数，动作只来自网络及声明的噪声。提供两个独立行为数据条件：

- 无噪声：当前默认，研究 BC 自身的自然错误。
- Gaussian 探索：候选归一化标准差 [0.06,0.06,0.04,0.04]，与当前配置一致。末端每轴噪声标准差约 0.6 mm，角度约 0.12°，开度约 1.6 mm；它可能不足以产生明显抓偏，需在 ID 试运行中量化状态覆盖后冻结。

不用专家干预或在线更新来增加这批数据的成功率。失败、超时和成功都保存。记录 checkpoint 哈希、噪声模式/参数/种子、动作后处理和机械臂控制器版本。正式评估统一无额外噪声；“带噪采集行为的价值”与“无噪评估策略的价值”不可直接混称为同一个目标。

## 7. 价值、优势与策略更新

价值训练默认使用预算一致的 BC/RECAP 完整 rollout。每个状态标签为该轨迹的完整 MC 回报，使用分布交叉熵拟合，同时报告期望值的 MAE/RMSE，并按成功/失败、控制阶段和期限余量分层分析。阶段和时间只用于离线分组。

默认 n=10，即 0.5 s。对 t 时刻，k 是不跨越任务终止的实际长度：

```text
A_t = sum(r[t:t+k]) + bootstrap - V(o_t)
bootstrap = 0                  if fragment reaches task termination
          = V(o_{t+k})          otherwise
c_t = 1[A_t > tau], tau = 0     # 正式协议明确等于阈值归低条件
```

保存 V、MC Return、n 步 Advantage、二元条件和产生标签的价值 checkpoint 哈希。阈值、n、条件权重仅由独立的 ID 验证场景确定，最终测试不参与。当前同一价值模型可以为其训练轨迹打标签，正式报告必须说明这一点；按完整轨迹做交叉拟合可作为抗过拟合消融，而不默认把计算成本扩大数倍。

策略保留普通监督路径和条件监督路径。条件策略使用全部成功和失败 rollout，低条件样本也参与拟合，推理时固定 c=1。专家保留项用于维持初始技能，可令专家动作走高条件，但这是监督锚点，不是声称专家已被价值模型证明为正优势。

建议把目标写清楚：

```text
L = (1-rho) E_rollout[w(c) * MSE(pi(o,c),a)]
    + rho E_expert[MSE(pi(o,1),a)]
rho=0.25, w(1)=1, w(0)=1 为初始设置
```

当前 `expert_ratio=0.25` 实现的是上述损失权重：每步采 256 条 rollout 和额外 256 条专家，而不是总 batch 中恰好 25% 专家。应明确命名/记录这一区别；若改成固定总 batch 的按比例采样，需要新协议并让所有更新基线一致。

在线多轮默认先采用 `latest_round`：V 对应上一轮冻结行为策略，含该轮的成功与失败。这使价值目标容易解释。现有默认是 `all_rounds`，会按拼接后的转移采样，长轨迹和数据量大的轮次权重更大，V 近似这个占用分布下的混合行为回报，不是某一个当前策略的 V。历史数据混合作为单独消融，报告每轮占比；如采用各轮等权，需新增显式采样实现。

## 8. 固定数据基线、在线迭代与预算

第一组只用同一批初始专家、同一 BC checkpoint 和同一 frozen BC rollout：

| 方法 | 更新数据 | 优势条件 | 比较目的 |
|---|---|---|---|
| 初始 BC | 成功专家 | 无 | 冻结起点，额外训练/交互为零 |
| 专家 BC 继续训练（待补） | 原专家 | 无 | 控制额外优化本身的收益 |
| 聚合数据 BC | 全部 rollout + 相同专家保留项 | 无 | 控制数据增加的收益 |
| 仅成功轨迹 BC | 成功 rollout + 相同专家保留项 | 无 | 对照整轨迹成功筛选 |
| RECAP 式更新 | 全部 rollout + 相同专家保留项 | 有，推理 c=1 | 检验状态动作级优势条件 |

当前 `compare` 包含初始 BC、聚合数据 BC、仅成功轨迹 BC 和 RECAP 条件更新；全部 rollout 的普通监督更新统一使用 `aggregate_bc`。成功 rollout 不足时，报告该基线不可训练/无法可靠划分，不能偷偷用专家代替它的数据。任何扩大采集量的决定须对整组更新方法同时应用。

各更新方法相同初始权重、优化器、优化步、实际每步样本数、专家损失权重、验证场景与 checkpoint 选择机会。条件输入新增列用零初始化，使初始输出与 BC 一致。建议统一每 5 个 epoch 做一次 ID 策略验证；当前 BC 每 5 个 epoch、更新默认每个 epoch，正式比较前需统一。所有方法训练至同一预算后再用同样规则选择 best；同时保存 last 以便续跑。

当前 arm3r 配置继承以下预算，它们是调通起点，尚未证明收敛：

| 阶段 | 当前数据量/预算 | 建议的两阶段实验规模 |
|---|---|---|
| 专家 | 100 条成功示范，无任务期限 | 先保留 100 做 ID 试运行；正式候选 500 条 |
| BC rollout | 200 回合，最多 300 步 | 试运行 200；正式候选每轮 500 回合 |
| BC 训练 | 40 epoch×50 更新=2000 步，batch 256 | 用 ID 学习曲线确定统一预算 |
| Value 训练 | 2000 步，batch 256 | 同时看训练与完整轨迹验证误差 |
| 策略每轮更新 | 2000 步，rollout batch 256，额外专家 batch 256 | 所有更新基线使用相同计算预算 |
| Adam 学习率 | 三者均为 3e-4 | ID 试运行后冻结 |
| 在线轮数 | 当前 1 轮 | 固定数据有效性检查后再做 3 轮 |
| 训练种子 | 当前 1 个 | 先 3 个，最终建议 5 个 |
| 每个测试套件 | 当前 100 场景 | 正式候选 200 场景，各方法完全配对 |

如果 2000 步尚未达到 ID 学习曲线平台，可在正式比较前统一增加，不根据最终测试或某个方法的最终分数单独延长。500 回合×300 步给出每轮最多 150000 次环境交互；在线 3 轮为最多 450000 次/方法/训练种子。报告实际步数、上限、验证/测试交互和额外末轮评估 rollout，不把评估或生成恢复池的成本藏起来。

正式在线主比较建议仅保留聚合 BC 与 RECAP，控制总成本。每轮二者从各自上一轮 checkpoint 更新，采集相同数量的新场景；对应场景种子相同，轨迹结果允许不同。每轮冻结采集、训练、再采集，不在采集过程中更新网络。一次试运行无法预测服务器用时，先记录实测采集速度、GPU 更新速度和磁盘占用再排期。

优先消融：n∈{1,10,30}；专家保留权重∈{0,0.25}；无噪声/配置噪声；latest_round/all_rounds。一次只变一个因素，避免全因子组合扩大成本。硬/软 bins 和优势阈值敏感性放在价值诊断表，不必先把全部因素同时扫一遍。

## 9. 统一训练、验证和测试分布

当前不设置 OOD。原短悬伸和高台座范围全部纳入统一 ID，数据版本为 `arm3r_upright_stable_target_no_relative_v2`。

| 因素 | 统一范围 | 采样规则 |
|---|---|---|
| 台座高度 | 12–19 cm | 连续均匀 |
| 悬伸量 | 3.0–4.6 cm | 连续均匀 |
| 目标中心 x | 12–20 cm | 连续均匀 |

三个参数独立采样，包含原范围之间的间隙；全部组合都允许进入训练，不留出短远等布局。专家、冻结策略 rollout、验证和测试使用完全相同的环境范围，分别由 expert、rollout、validation、evaluation 种子控制。验证用于 checkpoint 选择，最终测试只报告性能；同分布不等于复用训练轨迹。

`evaluation.suites`仅包含`id`，不接受`scenario_overrides`。每个方法默认测试100个ID回合，空抓/掉落恢复池单列诊断。历史外推结果按原始配置保留，不能改标为当前ID结果或混入新训练集。场景分布已变更，需要新run重新采集、冻结contract并训练；奖励规则和成功条件保持原版本。

为减少固定预抓姿态的记忆捷径，未来可加入合法初始 TCP 扰动：水平 ±1.5 cm、高度 ±1 cm、末端角度 ±5°。该扰动尚未接入当前 reset；如果启用，需先检查IK和初始无穿透，并对训练、验证、测试使用同一规则和新数据版本。

摩擦、质量、尺寸、重力和控制频率在主实验固定。物理验收覆盖范围内部及边界交叉组合；物理可行性不代表学习策略已达到相同成功率。最终测试种子在训练前固定，不根据最终分数调参或删除失败场景。若初始几何无效，应按预先声明的物理规则整体修订场景版本并记录原因。

## 10. 抓偏、动作排序与恢复实验

### 10.1 状态价值诊断

从真实仿真运行到抓取前，然后通过有限幅动作移动到不同偏差，而不是直接改物体状态。侧抓主要扰动 z，高度偏差候选 [-12,-6,0,6,12] mm；其次测试插入深度 x 和末端角度。每次只变一个因素，记录实际到达的偏差和速度。

每个偏差状态保存完整状态，以与价值训练目标相同的冻结参考行为续跑，比较 V 与实际剩余回报。若值模型来自带噪 BC，就用同样噪声规则作为主校准参考；无噪 BC 续跑另列。跨多个基础布局取样，正式候选至少 30 个，不把一个场景的漂亮曲线当成总体规律。

确定性参考每个状态续跑一次即可；多次相同执行不是独立样本。随机参考可用 20 个独立续跑噪声种子估计期望与不确定性，并在分支间配对种子降低方差。

### 10.2 等长纠错片段排序

同一错位状态分别执行“直接闭合”“向正确方向纠正后闭合”“向错误方向移动后闭合”，片段长度 K=10 控制步，随后用同一个参考行为续跑。每个分支有相同起始内部步数和相同总任务期限；片段提前终止则不再 bootstrap。

主排序可直接比较三种实际干预的总回报和估计 K 步优势；闭合时机本身属于干预差异，不能把效果全归于方向。另做匹配闭合时机的控制组：前 4 步保持/正确移动/错误移动，后 6 步均闭合。这样区分纠正方向与多等待几步的影响。

报告成对排序准确率、三分支最佳动作命中率、实际收益差及估计收益差；近似平局单列，不强制排高低。除侧抓外，再诊断旋转中滑移和落位前倾角偏差，避免把整个任务的能力等同于抓取高度校正。

### 10.3 真实恢复状态池

用真实 rollout 加可重放的动作扰动生成：空抓、尚未完全脱离双指的滑移、以及已经掉落的状态。每个状态保存场景、MuJoCo 积分状态、执行器/控制器状态、专家生成器状态、随机数状态、内部步数、事件历史和原始剩余预算。评估策略共享同一状态和预算，剩余预算不输入网络。评估池完全隔离，不作为训练或 checkpoint 选择数据。

必须区分“物理有效”与“参考控制器已证明可恢复”。12 cm 长物体若完全横躺平桌，8 cm 夹爪不能直接从上方跨过长边闭合，下手指也可能无法插入桌面下方；当前没有完整推扶重定位技能。不能承诺任意掉落都可重抓。

主恢复指标包括全部预先生成状态的成功率，并按空抓、滑移、掉落及参考可恢复性分层报告。可另列经过独立参考流程验证的可恢复子集，标明筛选规则和分母；参考失败只表示未证明可恢复，不能直接贴“物理不可能”标签。若要专门研究完全平躺后的恢复，应作为下一版加入推扶技能或声明新的场景结构，不能偷偷加隐藏吸附或放宽开度。

## 12. 报告与实施顺序

主表按方法和统一 ID 测试/空抓恢复/掉落恢复列成功率，跨训练种子报告均值和离散程度。场景成功率区间与训练种子不确定性分别表达；同一组固定场景上的方法差异用配对比较。禁止把一个训练种子的数百场景当成数百次独立训练实验。

同时报告：首次抓取成功率、空抓次数、掉落次数、重抓次数、恢复成功率、成功轨迹完成时间、超时率、失败原因、最终位置/倾角误差、释放后稳定性、价值 MAE/RMSE 与分布损失、优势排序、IK 回退和力矩饱和比例。首次抓取应定义为第一次闭合后成功试抬并持续支撑物体，事件计数加去抖；当前单步接触事件统计需加强。完成时间只在成功轨迹上统计，同时给成功率和超时率。

每轮固定导出代表轨迹：首次成功、空抓后恢复、掉落/倾倒失败，以及不同高度/悬伸组合下的成功与失败；按预声明规则选样，不只挑最好看的。曲线对齐显示 V、真实 Return、n 步 Advantage、动作与物体姿态，专家阶段仅作图注。

实施顺序及验收：

1. **物理与定义。** 补全碰撞/IK/力矩日志和合法初始扰动；在统一 ID 范围内部和边界组合做真实专家验收，确认恢复预算。冻结当前场景与成功定义。
2. **专家与 BC 闭环。** 补持久 split、周期性保存、动作审计；采专家、确认 H/C_fail/support，训练 BC、冻结采集自然错误数据。检查成功与失败是否有足够覆盖。
3. **价值和纠错诊断。** 完整 MC 训练、留出轨迹校准、多个基础场景的价值曲线与等长片段排序，验证标签未跨终止、无时间/阶段泄漏。
4. **固定数据 RECAP 比较。** 统一 checkpoint 选择次数、专家权重与实际 batch；去除重复基线，完成多训练种子比较。结果不佳也如实保留。
5. **在线与统一分布评估。** 固定上一阶段协议，进行 3 轮匹配交互预算的迭代；最后统一测试独立 ID 场景和恢复池，导出论文式图表及回放。

不以任意规定的成功率作为“必须调到”的门槛。工程验收关注数据、动力学和统计协议是否正确；方法有效性由最终对照实验决定。
